# ☕ Coffeshop

Landing page responsiva de uma cafeteria fictícia, com banner de destaque, categorias, vitrine de produtos, depoimentos e menu mobile.

> **Projeto demonstrativo** — criado para fins de estudo e portfólio. Os produtos, preços e depoimentos são fictícios.

🔗 **Demo:** [adicione aqui o link da Vercel](https://seu-projeto.vercel.app)

## Funcionalidades

- Layout responsivo (desktop, tablet e celular)
- Menu hambúrguer para telas pequenas
- Barra de busca no cabeçalho
- Seções de categorias, produtos (cafés e sobremesas) e depoimentos
- Efeito de animação nas imagens ao passar o mouse

## Tecnologias

- **HTML5**: estrutura semântica
- **CSS3**: Flexbox, Grid e media queries
- **JavaScript**: interações do menu
- **Google Fonts**: Playfair e Roboto

## Como rodar localmente

```bash
git clone https://github.com/MayconH94/coffeshop.git
cd coffeshop
```

Depois, abra o `index.html` no navegador (ou use a extensão Live Server do VS Code).
